Icon assets for Saheli ASHA-friendly UI
========================================

Place SVG or PNG icon files here. These are referenced in ui/templates/index.html
for low-literacy symbol-based navigation.

Suggested icons (free sources: Flaticon, Material Icons, Noun Project):

  mic.svg          — Microphone / Record symptoms button
  camera.svg       — Camera / Add patient photo button
  history.svg      — Patient history / Medical records button
  green_check.svg  — GREEN risk result banner
  yellow_warn.svg  — YELLOW risk result banner
  red_alert.svg    — RED emergency banner
  ambulance.svg    — Call ambulance action button
  referral.svg     — Refer to facility action button
  patient.svg      — New patient registration button

All icons should be:
  - Minimum 64×64 px when rendered
  - High contrast (WCAG AA) for outdoor use on bright screens
  - Recognisable without text labels (low-literacy users)
